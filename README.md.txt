# 🎮 Krishna Pygame Project

A simple animated picture developed using **Python and Pygame** as a practice project while learning Python animation development

## 🛠️ Technologies Used

* Python 3.12
* Pygame 2.6.1

## 🚀 How to Run

### 1. Install Python

Make sure Python 3.12 or a compatible version is installed on your system.

### 2. Install Pygame

Open a terminal and run:

```bash
py -3.12 -m pip install pygame
```

### 3. Run the animation

Navigate to the project folder and run:

```bash
py -3.12 "krishna pic.py"
```
